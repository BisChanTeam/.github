# 📱 БисЧан — уникальный мессенджер для фандома Бискаса

**Статус:** 🚧 *Проект находится в активной разработке*

БисЧан — это экспериментальный мессенджер, созданный специально для фандома ютубера **Бискаса**, а также всех, кто хочет присоединиться к нашему уютному сообществу.

Мы вдохновились обычной шуткой из Telegram-канала **Roflbis**, но затем решили сделать из идеи нечто большее — **полноценный мессенджер с собственным функционалом, ключами и безопасностью.**

---

## ❓ Как появился БисЧан

История началась с шуточного поста, который неожиданно вдохновил нас на создание своего мессенджера.
Теперь проект развивается в сторону настоящего приложения для общения.

## ❓ Что такое БисЧан

БисЧан — это **уникальный мессенджер для всего фандома Бискаса и других желающих**, который стремится объединить людей в одном дружелюбном и безопасном пространстве.
